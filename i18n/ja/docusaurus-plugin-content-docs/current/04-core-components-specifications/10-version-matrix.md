このページでは、MaaS Blender の各コンポーネントと、データフォーマット仕様などの外部依存関係とのバージョン互換性をまとめています。
入力データの準備や個別コンポーネントのアップグレードの際にご参照ください。

## バージョンタグ

MaaS Blender は OTP バージョンと GTFS Flex 仕様のバリアントを組み合わせた異なるバージョンを管理するために以下のタグを使用しています。

| リリースタグ | OTP バージョン | GTFS Flex 仕様 |
|--------------|:--------------:|:--------------:|
| v0.5.0       |      2.4       |    ドラフト    |
| v1.0.0       |      2.6       |      標準      |
| v1.1.0       |      2.9       |      標準      |

## GTFS Flex 互換性

[GTFS Flex](https://gtfs.org/extensions/flex/) は、初期のドラフト仕様と GTFS 標準に正式に組み込まれたバージョンとの間で構造的変更がありました。
この2つのバリアントには、カラム名の一部に変更があり、ロケーショングループの所属関係の表現方法が異なります。

### 仕様の違い

| フィールド / ファイル                                  | GTFS Flex 仕様ドラフト                        | GTFS Flex 仕様標準                   |
|--------------------------------------------------------|-----------------------------------------|----------------------------------|
| ロケーショングループの参照                             | `location_groups.txt` の `location_id` 列 | 別ファイル `location_group_stops.txt` |
| `stop_times.txt` の停留所参照                          | `stop_id` 列                             | `location_group_id` 列            |
| ピックアップ/ドロップオフ開始時間のカラム名 | `start_pickup_dropoff_window` | `start_pickup_drop_off_window` |
| ピックアップ/ドロップオフ終了時間のカラム名 | `end_pickup_dropoff_window` | `end_pickup_drop_off_window` |

### コンポーネントサポートマトリクス

| コンポーネント             | ドラフト仕様 | 標準仕様 |
|----------------------------|:------------:|:--------:|
| ルート逸脱シミュレーター   |      -¹      | > v1.0.0 |
| オンデマンドシミュレーター |    v0.5.0    | > v1.0.0 |
| シンプルプランナー         |    v0.5.0    | > v1.0.0 |

¹ ルート逸脱シミュレーターは GTFS Flex 標準仕様のみ対応しています。
